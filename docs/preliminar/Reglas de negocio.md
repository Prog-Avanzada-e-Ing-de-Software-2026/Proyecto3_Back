1. Solo los profesores pueden armar los planes de entrenamiento.  
2. El plan no puede ser para más de 5 días (el gym solo abre 5 días a la semana) y debe ser para al menos 1\.   
3. El plan se divide en tres partes: core, movilidad, y fuerza.   
4. El plan debe si o si tener ejercicios para todas las partes (no puede no tener core o movilidad).   
5. Los bloques de movilidad y core son iguales para todos los días del plan, mientras que el bloque de fuerza es particular de cada día.  
6. El plan se separa en bloques de movilidad, core y fuerza (este último incluye la parte principal del entrenamiento, todo lo que no sea movilidad o core).   
7. Un plan personalizado se puede crear copiando otro plan personalizado que haya creado ese profesor anteriormente. Los planes personalizados tambien se pueden crear desde 0\.  
8. Todos los ejercicios comparten la misma progresión semanal, si se quiere indicar algo diferente para uno se hace como comentario.  
9. El plan y entrenamientos de un alumno son visibles para los profesores y solo para ese alumno.   
10. Un plan es para 4 semanas.   
11. Un profesor puede cargar planes “futuros” (es decir, con una fecha de inicio posterior a la fecha de fin de su plan actual) para un alumno.  
12. El plan que se le muestra a un alumno para guiarlo es el que abarca la fecha actual.  
13. Un alumno no puede tener planes cuyas fechas se solapen.    
14. El record de ejercicio es el mayor peso levantado en el caso de los ejercicios a los que se les carga peso y la mayor “cantidad” para aquellos sin peso.   
15. Al dar de baja un profesor, sus alumnos quedan sin profesor asignado, pudiendo luego ser reasignados.   
16. Un alumno dado de baja no puede registrar entrenamientos, pero su historial se conserva.  
17. No se le puede hacer un plan a un alumno dado de baja.  
18. Un profesor dado de baja no puede acceder a la aplicación.  
19. Un alumno dado de baja puede volver a darse de alta y el seguimiento de progreso debe continuarse donde quedó.  
20. Reps ≥ 1 y peso ≥ 0 (o ausente)  
21. Un alumno tiene un único entrenamiento en curso a la vez.  
22. Un entrenamiento finalizado es inmutable.  
23. Un ejercicio no se puede repetir dentro del mismo día del plan.  
24. Un ejercicio no se puede repetir dentro del mismo entrenamiento.  
25. Los ejercicios del día se deben ofrecer como guia, junto con la carga de trabajo que corresponde a la semana.   
26. Un entrenamiento se asocia al plan activo del alumno y a un día de ese plan, pero el alumno puede registrar cualquier ejercicio del catálogo, esté o no en el plan y no es obligatorio registrar todos los ejercicios del día del plan.
